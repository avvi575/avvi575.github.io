Family Expense Tracker
Personal Project
Apr 2025 – Present  |  Open Source

Full-stack expense tracker for families featuring multi-user accounts with roles (Admin/Member/Viewer), recurring expenses with auto-materialization, budget alerts, savings goals, notification feeds, and a reconciliation workflow for imported bank/credit-card statements. Built with JWT auth, PostgreSQL, Prisma ORM, multer uploads, nodemailer, and a Python PDF parser supporting 15+ Indian bank/card formats.

  • Dual-stack: NestJS backend API serving both web dashboard and Android Kotlin client from a single codebase.
  • Multi-schema PostgreSQL design separating raw imports from finalized expenses for safe concurrent editing.
  • Python cc-parser library with bank-specific profiles (HDFC, ICICI, SBI, Axis, HSBC, etc.) using pdfplumber for PDF extraction.
  • Dashboard with date-range filtering, aggregation granularity (Daily/Weekly/Monthly), and contributor breakdown.
